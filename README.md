# Ecom

> Modern e-commerce application with a product-management and administrative interface.

## Overview

Ecom is an e-commerce project organized around a modern web application and an admin-facing experience. The repository demonstrates product-oriented application development, frontend architecture and monorepo-style organization.

## Key areas

- E-commerce application workflows
- Product-oriented interfaces
- Administrative dashboard experience
- Modern Next.js application structure
- Monorepo/workspace-oriented development
- TypeScript-based development

## Technology stack

- Next.js 14
- React 18
- TypeScript 5
- Tailwind CSS
- Prisma tooling
- ESLint

## Architecture

```text
E-commerce UI
     |
     v
Next.js Application
     |
     +---- Product / Store Features
     |
     +---- Admin Interface
     |
     +---- Shared Workspace Code
     |
     v
Application Data Layer
```

The repository is structured as a workspace-based project, making it suitable for separating application concerns and shared packages as the product grows.

## Development

Clone the repository and install the project dependencies using the package manager configured by the workspace.

```bash
git clone https://github.com/Oluwatobi843/Ecom.git
cd Ecom
npm install
```

Start the development application with the project's configured development command.

```bash
npm run dev
```

Build for production with:

```bash
npm run build
npm run start
```
